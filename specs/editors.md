# The editors

- The object list shows these categories, in this order:
  - Actors
  - Assemblies (every assembly), Assemblies - Passages, Assemblies - Prefabs,
    Assemblies - Rooms; in the editors, not in in-game building, also Assemblies - Schemes
  - Bombs, Brains
  - Bunker Backgrounds (with the decorations the game files as Bunker Clutter), Bunker
    Bits, Bunker Modules, Bunker Odds & Ends, Bunker Systems
  - Craft, Crates, Deployments, Shields, Terrain Objects, Tools
  - Weapons, then Weapons - CQB, - Explosive, - Heavy, - Light, - Melee, - Primary,
    - Secondary and - Sniper
  - Wildlife, last

  Every item of a category no longer shown is listed in the category that took its
  place (Actors - Heavy's in Actors, Tools - Diggers' in Tools, and so on). A mod's own
  categories are listed as the mod names them.
- The object list has no Actor Spawners category and never offers the Generic Actor
  Spawner. The released game (v6.2.2) had neither.
- The object list opens with Actors selected, as in the released game, except where the
  editor picks a category itself: Brains while a brain still has to be placed, then
  weapons right after it is placed.

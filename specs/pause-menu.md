# The pause menu

- In a scenario, the pause menu reads, top to bottom: Restart Scenario; a gap; Back
  to Scenario Menu, Save or Load Game, Settings and (where upstream shows it) Mod
  Manager; a gap; Resume. Restart Scenario starts the scenario over.
- In Conquest and in the editors it is upstream's menu, without Restart Scenario.
- Once a scenario is lost, Esc, Space or Enter opens the same menu with Restart
  Scenario; a gap; Load Game and Exit to Menu. Load Game offers loading only, and a
  game loaded from there is played at once; Exit to Menu goes to the Scenario screen.

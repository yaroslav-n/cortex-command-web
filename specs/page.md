# The page

- The start screen offers a single button, "Play Game": no download size and no
  other text.
- Under the game, a strip:
  - on the left, "Open fullscreen by pressing Ctrl + F", and Ctrl+F does open
    fullscreen;
  - on the right, three links separated by bullets, each with an icon and a faint
    underline: "Cortex Command Web" (GitHub icon) to
    https://github.com/yaroslav-n/cortex-command-web, "Cortex Command Community
    Project" (GitHub icon) to
    https://github.com/cortex-command-community/Cortex-Command-Community-Project, and
    "Submit a bug" (bug icon) to a new issue on this port's repository,
    https://github.com/yaroslav-n/cortex-command-web/issues/new.
- A link to the page shared on X or another site shows a large preview: the title
  "Cortex Command Web", the line "The whole of Cortex Command, running in your
  browser: a web version of Cortex Command Community Project." and the Cortex Command
  Community Project title over a battle (`site/social-preview.jpg`, 1200×630).

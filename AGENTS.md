# Instructions for agents

Always check [`specs/`](specs/) before changing the app. It holds the app's specs: the
rules the user has set for how the game and its page must behave. Every change must
keep them true; if a request conflicts with one, say so before going ahead. When the
user sets a new rule, add it there.

How things work, and why, is written up in [`notes/`](notes/README.md).
